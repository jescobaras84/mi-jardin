# Mi Jardín 🌿
App para cuidar plantas (tierra e hidroponía) que se instala en cualquier teléfono.

- **Abrir:** https://TU-USUARIO.github.io/mi-jardin/
- **Instalar en iPhone:** Safari → Compartir → «Agregar a pantalla de inicio».
- **Pasar tus datos:** ⚙️ Ajustes → «Importar respaldo» → elige tu archivo `mi-jardin-respaldo-….json`.
- **Respaldo:** ⚙️ Ajustes → «Exportar respaldo» (guárdalo en Drive/OneDrive, nunca en este repo).
